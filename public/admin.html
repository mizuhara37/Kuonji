投稿与分类

输入 B 站视频的 bvid（或直接粘贴视频链接）即可投稿。视频画面、简介与 UP 主信息 全部来自 B 站，本站只保存元数据并调用官方播放器。

ℹ️ 支持一次粘贴多条：每行一个 BV 号或链接，也可以用空格 / 逗号分隔。 重复的 BV 号不会被重复添加，重新提交会刷新该视频的元数据（并保留它的分类）。
🛡️ B 站会对云主机（Vercel 等）的出口 IP 返回 412 request was banned。 遇到这种情况投稿不会失败：BV 号会先存下来，封面 / 简介 / UP 主信息在之后有人访问该视频时自动重试补齐 （也可以在下面点「补齐元数据」手动重试）。勾选「只存链接」可以直接跳过抓取。
